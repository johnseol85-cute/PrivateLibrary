# PrivateLibrary

개인용 **성서 원어 연구 라이브러리**와 **주해 작업 사이트**.

- 히브리어 구약·헬라어 신약 원전을 **정확한 좌표(책·장·절·단어)**로 보고
- 그것을 **한국어**(번역, 단어별 대역, 문법 설명)로 함께 보며
- 주요 대학 성서학의 **기초 주해 방법론** 순서대로 본문을 연구하고
- 연구 결과가 **나만의 주해 노트(주석)**로 쌓이는 것을 목표로 한다.
