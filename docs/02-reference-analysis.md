# 02. 참고 사이트 분석: Scriptorium AI (aipastors.org)

스크린샷: `docs/reference/screenshots/` (01 랜딩, 02 대시보드, 03 원전 검색, 04 분류 목록)

> aipastors.org는 분석 환경의 네트워크 정책상 직접 접속하지 못했고, 사용자가 제공한 스크린샷으로만 분석했다.

## 1. 서비스 개요 (랜딩)

- 문구: "질문하면, 원전이 답합니다" / "AI의 모든 문장 옆에 사료의 좌표가 붙습니다. 검증을 통과한 인용만 화면에 오르고, 근거가 없으면 없다고 말합니다."
- 규모 표기: 고대 원전·사본 89,887종 · 주석·연구 3,194종 · 판본 219종 · 절 단위 대조 2,062,290절
- 화면 예시: 실물 사진(사본 이미지) | 아카드어 원문(좌표: ARIo ...) | 내 언어로 AI 번역 — 3단 병행

## 2. 정보 구조 (대시보드)

| 영역 | 기능 |
|---|---|
| 원전 | 원전 검색, 병행 비교, 원문 읽기, 성경(장별 읽기), 성경 지도, 판본 대조 |
| 연구실 | 연구 보고서, 에이전트 갤러리, 학자 대화, 원탁, 워크플로우, 스킬 라이브러리 |
| 목회 도구 | 도구 카탈로그, 원클릭 주간 목양, 설교 준비 브리프, 쇼츠 클립, 워십 스코어 메이커 … |
| 내 공간 | 내 서재(설교·노트·PDF를 원전과 함께 검색), 내 루틴, 받은편지함, 설교 계획표 |
| 모임터 | (미확인, 커뮤니티로 추정) |

설계 특징:
- **목회자/연구자 모드 전환** — 기능은 같고 대시보드 배치만 바뀜.
- **교차 언어 검색** — 한국어로 물어도 원어 사료가 결과로 나옴(임베딩 색인 추정).
- **내 서재** — 개인 자료와 공개 원전이 한 검색 공간.
- **루틴 + 받은편지함** — 예약 실행되는 비동기 작업.
- **사용량 계량** — "이번 달 0 / 50" (SaaS 플랜 설계).

추정 아키텍처(5계층): ① 코퍼스·좌표 → ② 검색 → ③ AI 생성(인용 검증) → ④ 에이전트 → ⑤ 출력 채널.
**진짜 자산은 ①②**이고, ③~⑤는 그 위에 얹는 것.

## 3. 원전 검색 화면

분류별 수량:

| 분류 | 수량 | 비중 | 출처 추정 |
|---|---:|---:|---|
| 고대근동·사본 | 77,924 | 약 86% | ORACC·CDLI 등 설형문자 코퍼스 (점토판 1장 = 1종) |
| 성경 본문 | 3,477 | 4% | 판본·번역본 권 단위 |
| 신학 저작 | 2,640 | 3% | CCEL, EEBO-TCP 등 |
| 교부·초기 기독교 | 2,627 | 3% | First1KGreek, CCEL |
| 그리스·로마 고전 | 2,232 | 2% | Perseus/Scaife |
| 유대 문헌 | 1,072 | 1% | Sefaria |
| 신앙·실천 / 문학·일반 / 사전 | 370 / 178 / 81 | 소량 | Gutenberg 등 |

→ "8.9만 종"의 대부분은 고대근동 점토판. **숫자 경쟁은 의미 없음.**

검색 설계:
- **범위 선택 후 검색** — 체크한 분류 안에서만 찾음(메타데이터 필터).
- **연구 렌즈 32개** — 저장된 자료 묶음(필터 프리셋)으로 추정.
- **입력 유형 자동 구분** — `주제`(의미 검색) / `본문`(요 1:1 → 좌표 직행) / `질문`(검색+AI 답변). 성구 참조는 정규식 파서로 처리.
- **"격리(비공개) 자료는 구조적으로 검색되지 않습니다"** — 라이선스별 저장 계층 분리. 상업화를 위해 첫날부터 필요.

## 4. 자료 보관 방식 (추정)

- 텍스트: **자체 서버에 복사**(정확한 수량, 교차 언어 의미 검색, 절 단위 정렬, 격리 설계가 근거). 대부분 PD/CC 라이선스라 출처 표시 조건으로 복제·가공 허용.
- 사본 이미지: 원 기관 서버에서 **IIIF**로 불러올 가능성이 높음(재배포 제한, 용량).
- 원자료 링크: CC BY는 출처 표시가 의무이므로 문헌 단위 출처 + 가능하면 구절 단위 딥링크를 제공할 것으로 추정.

## 5. 우리 프로젝트에 가져올 것

- 가져갈 것: 좌표 체계, 범위 선택 검색, 입력 유형 구분, 라이선스 계층 분리, 출처 링크, 병행 보기
- 나중에: AI 질문·인용 검증, 내 서재
- 안 할 것: 목회 콘텐츠 생성 도구, 숫자 경쟁식 대량 수집
