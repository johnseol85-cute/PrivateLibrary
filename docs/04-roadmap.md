# 04. 구축 로드맵

> 기준(2026-10-07 재확인): **성경 원전 탐구 라이브러리 우선** — 히브리어·헬라어 원전 + 한국어 + 원어 탐구 도구. 주해 작업대는 이후 확장.
> 핵심 구조: 한 번 만든 "공장"(수집 → 정제 → 빌드)에 재료만 바꿔 넣는다.

## 전체 지도

```
 0. 준비 → 1. 설계 → 2. 수집 → 3. 정제 → 4. 빌드 → 5. 리더 → 6. 원어 탐구 → (확장: 주해 작업대 등)
           (그릇)    (재료)    (손질)    (포장)    (첫 사용)  (단어·용례·검색)
                       ↑_____________ 새 자료는 2→3→4만 반복 _____________|
```

| 단계 | 하는 일 | 사용자가 할 일 | 완료 기준 |
|---|---|---|---|
| 0. 준비 | Drive 폴더, Vercel·Turso 계정, 코드 뼈대 | 계정 연결 | 폴더·저장소·계정 준비 |
| 1. 설계 | 좌표 체계, 공통 데이터 형식, 출처 기록, 공개 등급, 한국어 대역 형식 | 샘플 검토 | 샘플(예: 룻 1장, 빌 1장) 승인 |
| 2. 수집 | 1차 자료 스냅샷 + `SOURCES.md` | 목록 확인 | 모든 항목 라이선스 확인 완료 |
| 3. 정제 | 출처별 변환 스크립트, 자동 검증(장·절 수 등) | 무작위 구절 대조 검수 | 자동 검증 + 샘플 검수 통과 |
| 4. 빌드 | `library.db`(FTS·좌표 색인) → Turso 업로드 | — | `룻 1:16` 조회, 원어 단어 검색 동작 |
| 5. 리더 | 장별 읽기, 원문·한국어 병행, 성구 이동, 출처 링크, 로그인 | 써 보고 피드백 | **매일 쓸 수 있는 원어 성경 리더** |
| 6. 원어 탐구 | 단어 클릭(원형·형태·사전 뜻), 같은 단어 용례 목록, 원어·한국어 검색 | 실제 본문으로 탐구해 보고 피드백 | **원전 탐구 라이브러리 완성** |

## 이후 확장 (보류)

- **주해 작업대**: 주해 7단계 화면, 구조 트리, 주해 노트 ([05](05-methodology-research.md) 참고)
- 이문·본문비평 심화(IGNTP 사본 전사 등), 칠십인역
- 교부·종교개혁 주석 연결(⑦ 성찰 단계 보강)
- 내 서재(개인 PDF·EPUB, "책 + 쪽" 좌표)
- AI 질문 + 인용 검증

## 완성 후 사용 모습 (예시)

1. `룻 1:16` 입력 → 원문 | 단어 대역(한국어) | 개역한글이 나란히
2. 단어 클릭 → 원형, 형태(한국어 문법 용어), 사전 뜻, 같은 단어 용례 목록
3. `용례` → 같은 원어 단어가 나오는 모든 구절 목록
4. 검색 → 원어(원형 기준) 또는 한국어로 구절 찾기
5. 각 절의 `출처 ↗`로 원 데이터 확인
