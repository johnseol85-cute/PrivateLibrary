# 05. 주요 대학의 성서학 교육과 기초 주해 방법론

> 조사일: 2026-10-07. 조사 환경에서 대학 웹사이트를 직접 열 수 없어 **웹 검색 결과와 그 요약**을 근거로 했다. 과목명·요건은 학년도마다 바뀔 수 있다.

## 요약

1. 교육 순서: **원어 → 개론(역사·문학 배경) → 주해(한 본문을 깊이) → 주해 논문·주석**.
2. 방법론은 하나의 공식이 아니라 **비평 도구의 묶음**으로 가르친다.
3. 기초 주해 표준 절차: **본문 확정 → 번역 → 문맥 → 형식 → 세부 분석 → 종합 → 신학적 성찰**.

## 2. 공통 원리

1. **원어가 입구** — 원어를 별도로 훈련하고 주해의 전제 조건으로 둔다(예일은 영어 주해 → 원어 주해의 다리를 둠).
2. **개론 → 주해** — 책 전체의 배경을 먼저, 그다음 한 본문을 깊이. 장르별(산문/시) 구분.
3. **방법론 = 도구 상자** — 본문비평, 역사비평, 양식·전승·편집비평, 내러티브 비평, 고대근동 비교 등을 본문에 맞게 선택.
4. **본문비평과 번역 비교가 기초 훈련에 포함** (케임브리지 1학년).
5. **최종 산출물은 주해 논문·주석** (하버드 학생 주석, 에모리 NT502).

## 3. 표준 교과서

- **Gorman, *Elements of Biblical Exegesis*** (3판, Baker 2020): 개관 → 문맥 분석 → 형식 분석 → 세부 분석 → 종합 → 성찰(신학적 해석) → 확장·정교화의 **7요소**. 샘플 주해 논문 수록.
- **Hayes & Holladay, *Biblical Exegesis: A Beginner's Handbook*** (4판, WJK 2022): 본문·역사·문법·문학·양식·전승·편집·구조주의·정경 비평을 **도구별로** 소개. 예: SMU 강의계획서(2026–27)에서 사용.
- 흔히 하나는 절차서(Gorman), 하나는 방법 개관(Hayes–Holladay)으로 함께 쓴다.

## 4. 이 프로젝트의 주해 7단계 (제안)

Gorman 7요소를 뼈대로, 원어 주해 앞단의 **본문 확정·번역**을 보강.

| 단계 | 핵심 질문 | 필요한 데이터 | 공개 데이터 지원 |
|---|---|---|---|
| ① 본문 범위·확정 | 단위는 어디까지? 원문은 정확히 무엇? | 원문, 이문 정보, 단락 구분 | 강함 |
| ② 번역 | 원문이 정확히 뭐라고 말하나? | 형태소, 사전, 번역 비교 | 강함 (한국어는 직접 제작 필요) |
| ③ 문맥 분석 | 역사적 상황과 책 흐름 속 위치는? | 개론, 앞뒤 본문 | 약함 → 내 노트 중심 |
| ④ 형식·구조 분석 | 장르와 구조는? | 구문 구조, 평행법 | 강함 (MACULA) |
| ⑤ 세부 분석 | 핵심 단어·문법·구문의 의미는? | 사전, 용례 색인, 구문 트리 | 강함 |
| ⑥ 종합 | 본문 전체의 주장은? | 내 노트 | — |
| ⑦ 신학적 성찰·적용 | 정경 전체와 오늘에 비추어? | 병행 본문, 상호 참조, 해석사 | 보통 (해석사는 이후 확장) |

## 5. 사이트 구상: "주해 작업대"

```
[본문 선택: 룻 1:1-5]
 ├ ① 본문    원문 · 단락 구분 · 이문 표시
 ├ ② 번역    원문 | 단어 대역(한국어) | 개역한글 | 내 번역 입력란
 ├ ③ 문맥    책 개관 · 앞뒤 본문 · 내 노트
 ├ ④ 구조    절·구 구조 트리 · 시 평행법
 ├ ⑤ 세부    단어 클릭 → 원형·형태(한국어 문법)·사전·용례
 ├ ⑥ 종합    내 노트
 └ ⑦ 성찰    병행 본문 · 상호 참조 · (이후) 교부·종교개혁 주석
        ↓
[산출물] 본문별 '주해 노트' → 쌓이면 나만의 주석
```
